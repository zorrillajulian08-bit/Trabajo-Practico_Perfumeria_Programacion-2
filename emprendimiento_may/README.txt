EMPRENDIMIENTO MAY - CATÁLOGO

Archivos:
- index.html: página principal y catálogo.
- perfume.html: detalle de cada perfume.
- css/style.css: diseño, responsive y animaciones.
- js/script.js: catálogo, buscador y filtro.
- js/perfume.js: detalle y zoom de imagen.
- images/: colocá acá las fotos.

Imágenes esperadas (nombres exactos):
9pm.jpg
SauvageDior.jpg
GoodGirl.jpg
Baccarat.jpg

Para abrir: descomprimí la carpeta y abrí index.html. Recomendado usar Visual
Studio Code con Live Server.

Para agregar o cambiar perfumes, actualizá el arreglo `perfumes` tanto en
js/script.js como en js/perfume.js. Los precios se muestran en formato argentino.
